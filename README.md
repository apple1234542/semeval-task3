# 瑞典语历时词义归纳：方法与实验总结

## 任务目标

历时词义归纳（Word Sense Induction，WSI）要求根据目标词在不同年代、不同句子中的上下文，将意思相同的用法归为同一类，将不同意思的用法分开。

例如，瑞典语 `motiv` 可以表示“动机”，也可以表示“图案或主题”。系统需要根据上下文识别这些差异。

本项目的处理流程为：

**句子输入 → 微调 XLM-R 提取目标词向量 → 按词聚类 → 输出预测标签 → 官方评测。**

## 2. 模型微调

### 基础模型与训练样本

使用 XLM-RoBERTa 编码器。每个训练样本包含：

- 一个锚点用法（Anchor）；
- 一个与锚点具有相同词义标签的正例（Positive）；
- 三个与锚点属于同一个词、但词义标签不同的负例（Negative）。

模型处理所有输入时共用一套参数。训练数据的标签决定正负例关系，模型学习如何将这种关系反映在向量中。

### 训练目标

v3 代码使用对称的多负例对比交叉熵：分别以锚点和正例为参照，在候选用法中识别正例。

v4 在此基础上加入对称间隔损失，总损失为：

```text
L_total = L_contrastive_CE + 0.5 × L_margin
```

对一个正负例关系，间隔项为：

```text
L_margin = max(0, 0.2 - similarity(A, P) + similarity(A, N))
```

实际训练对多个负例及反向关系取平均。其目标是让同义相似度高于异义相似度，并尽量达到设定的间隔。

### 微调验证结果

加入间隔损失后，三元组验证准确率没有明显提高，最佳仍约为 **0.785**。

该指标基于固定抽样的 **200 组三元组**：当正例与锚点的余弦相似度高于负例时，计为正确。准确率本身不要求相似度差达到间隔。

**三元组验证准确率与瑞典语 WSI 官方评分属于不同指标，不能直接比较。**

训练数据检查还发现了部分目标词、文本片段和标签可能不匹配的记录，以及历史拼写和异常文本。启发式检查标记只能用于复核，不能将全部被标记记录直接视为错误。

## 3. 目标词向量提取

使用微调后的模型读取句子，并根据 `start/end` 定位目标词。对于较长输入，使用以目标词为中心的窗口。

向量提取步骤：

1. 对最后若干个 Transformer 层的隐藏表示取平均；
2. 对目标词对应的子词表示取平均；
3. 对所得向量进行 L2 归一化。

每条用法得到一个 **768 维上下文向量**。同一个词在不同句子中可以得到不同向量，用于表达上下文中的词义差异。

推理阶段最大输入长度设为 **256**，批大小设为 **8**。提取后的向量保存为 `embeddings.npy`，后续调整聚类参数时可复用缓存。

## 4. 按词聚类

采用余弦距离与凝聚式层次聚类。每个目标词单独聚类，不将不同词的用法混在一起。

聚类阈值控制合并程度：

- 阈值较小，通常形成更多类别，可能将同义用法拆散；
- 阈值较大，通常合并更多用法，可能将不同词义混合。

初始统一阈值为 `0.25`，存在分组过碎的问题。例如，`dumpa` 被分为 19 类，`motiv` 被分为 18 类。

将统一阈值提高至 `0.425` 后评分改善，随后进一步按词调整阈值，并比较两种聚类方式：

| 聚类方式 | 合并时使用的组间距离 |
|---|---|
| `average` | 两组用法之间的平均距离 |
| `complete` | 两组用法之间的最大距离 |

### 官方评分 0.80 版本的配置

该版本使用最后 **4 层平均向量**。

| 词 | 聚类方式 | 阈值 |
|---|---|---:|
| suga | average | 0.300 |
| fru | average | 0.435 |
| herre | complete | 0.605 |
| motiv | complete | 0.580 |
| 其他词 | average | 0.425 |

## 5. 实验结果

### 已确认的官方结果

| 版本 | 官方子任务 1a 瑞典语评分 |
|---|---:|
| 四层平均向量，统一阈值 0.25 | 0.67 |
| 四层平均向量，统一阈值 0.425 | 0.78 |
| 四层平均向量，按词调整聚类 | **0.80** |

以上阶段保持模型权重不变，主要提升来自聚类参数调整。

### 隐藏层数量比较

进一步比较最后 1、2、4、8 层的向量，并为各版本分别搜索聚类参数。

| 向量提取方式 | 沿用四层最佳聚类配置 | 分别调参后的本地参考分 |
|---|---:|---:|
| 最后 1 层 | 0.6130 | 0.7721 |
| 最后 2 层平均 | 0.6910 | **0.8109** |
| 最后 4 层平均 | **0.8082** | 0.8082 |
| 最后 8 层平均 | 0.7635 | 0.7911 |

不同层的向量距离分布不同，因此仅固定阈值比较，不能充分判断哪种向量更好。

本地参考指标将真实标签存在交集的两条用法视为同义，计算每个词的 B³ 式 F1 后取平均。**此实现尚未与官方评分代码逐项核对，不能直接视为官方指标。**

## 6. 提交格式

每条用法输出目标词、句子 ID 和预测类别列表：

```json
{"word": "motiv", "sentence_id": "example_id", "label": [0]}
```

类别编号只是聚类标识，可以任意命名，不直接对应参考标签中的词义编号。本实现每条用法输出一个预测类别，尚未实现多标签归属。

提交前检查：

- 覆盖全部 1983 条用法；
- `(word, sentence_id)` 与输入用法集合一致；
- 无重复用法，标签格式正确；
- ZIP 根目录包含 `SV_subtask1.jsonl`。

示例压缩包结构：

```text
submission_sv_layer2_tuned.zip
└── SV_subtask1.jsonl
```

本次提交仅针对任务一的词义聚类预测，未生成任务二预测。

## 7. 结论与限制

本项目采用微调 XLM-R 的目标词上下文向量与按词层次聚类完成瑞典语历时词义归纳。已确认的官方评分从 **0.67 提升至 0.80**，主要改善来自聚类阈值与聚类方式调整。

需要注意：

- 训练三元组验证指标、本地参考指标和官方评分不能混为一谈；
- 按词阈值及层数选择使用了开发集参考标签，开发集成绩不代表独立测试集效果；
- 当前方法每条用法仅输出一个类别，对多义或模糊用法的多标签处理仍有改进空间；
- 后续可核对官方评测实现、分析 `skär` 和 `suga` 的混淆用法，并在独立数据上验证参数的泛化效果。
